Port 0x006B write: DMA (zxnDMA)
  decoded by: A7:A0 = #6B
  enabled: off (NR 0x82 bit 5, gated by the emulator: on)
  side effect: the next byte of the DMA's WR0-WR6 sequence; the zxn mode latch is set
