Unreal Speccy Emulator API

ZX Spectrum emulator with full REST API control

Open Swagger UI OpenAPI JSON List Emulators

API Tools

Swagger UI (built-in)
Open Swagger UI
Docker Swagger UI
docker run -p 8081:8080 \
  -e SWAGGER_JSON_URL=http://host.docker.internal:8090/api/v1/openapi.json \
  swaggerapi/swagger-ui
Then visit localhost:8081
Postman / Insomnia
Import OpenAPI: http://localhost:8090/api/v1/openapi.json

Quick Start

# List emulators
curl http://localhost:8090/api/v1/emulator

# Create and start emulator
curl -X POST http://localhost:8090/api/v1/emulator/start \
  -H "Content-Type: application/json" -d '{"model": "128k"}'

# Get registers (replace {id} with emulator ID)
curl http://localhost:8090/api/v1/emulator/{id}/registers
