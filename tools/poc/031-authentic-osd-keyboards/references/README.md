# POC 031 references

What each model's keyboard looked like and how it is wired, collected 2026-10-19 from photos, manuals, schematics,
firmware and other emulators. Every fact names its source; **UNVERIFIED** marks a photo measurement or a reading
without a written source.

| File | Machines |
|---|---|
| [next.md](next.md) | ZX Spectrum Next (cased, KS1 / KS2) |
| [sinclair.md](sinclair.md) | 48K, Spectrum+, 128 (UK, Spanish), +2, +2A, +3; the matrix and the extra keys of the 58-key keyboards |
| [clones.md](clones.md) | Pentagon, Scorpion (and PROF ROM, GMX), KAY-1024, Quorum, Orel BK-08, Profi |
| [pc.md](pc.md) | the PC-keyboard clones: ATM-Turbo, ZX-Evo / TS-Conf, Phoenix, Sprinter; the XT / AT / 101-key layouts |

`photos/<group>/` holds the photos and scans the files cite: references to measure and compare against, never
traced or embedded in a picture. Photos over 2400 px were scaled down to 2400 px on the long side.

`zx-spectrum-data/` in the sources is the owner's local collection of ZX Spectrum material (VHDL, firmware, manuals,
other emulators' sources), not part of the repository.
