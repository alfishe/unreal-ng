# z80n-fork - the Next's CPU library from the z84c15 core

`forkz80n.py` makes `core/src/3rdparty/unreal-next-z80` from the z84c15 fork (itself unreal-z80 0.5.0): it copies the core files under the
new names; the hand edits (Z80N opcodes, NEXTREG, stackless NMI, the RETN aliases) are listed in that library's README. Used once to
create the library; re-run only to rebase the fork.
