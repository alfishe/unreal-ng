# TS-Conf tools

Tools for the TS-Conf machine (ZX-Evolution with the TS-Conf firmware).

| Folder | What it does |
|:--|:--|
| [rtl-sim/](rtl-sim/README.md) | Verilator harness for the real TS-Conf video Verilog: captures per-pixel palette indices of a raster line; answers what G_X_OFFS does in ZX and text mode |
| [vdac2/](vdac2/README.md) | VDAC2 card (FT812): extracts the FT81x ROM image the emulator needs for the FT812's ROM fonts |
