# Loader: Hobeta (`$`-files, single TR-DOS file container)

> Part of [2026-09-02-universal-track-model](README.md). Status: **implemented**
> (`core/src/loaders/disk/loader_hobeta.{h,cpp}`, tests `core/tests/loaders/disk/loader_hobeta_test.cpp`).
> Not a disk image: a single TR-DOS file with a 17-byte header. Loading means "inject this file into a (new or
> existing) TR-DOS disk", exactly what `LoaderSCL::addFile()` already does for SCL entries.

## 1. Format

```
0x00  8   file name (TR-DOS, space padded)
0x08  1   type / extension character (B, C, D, #, …)
0x09  2   start (BASIC: autostart line; CODE: load address)
0x0B  2   length in bytes
0x0D  1   (unused / first byte of length in sectors in some tools) — preserved verbatim
0x0E  1   length in sectors
0x0F  2   checksum = Σ(i=0..14) header[i] × 257 + i   (16-bit, little-endian)
0x11  …   data, sectors × 256 bytes
```

## 2. Mapping to the model

* Validate checksum and `sectors × 256 == fileSize − 17` (`LoaderHobeta::detect` / `parseHeader`).
* `loadImage()`: new DS80 image formatted with `LoaderTRD::format()`, file injected, image marked clean and loaded
  (ownership to the caller via `getImage()`, same as SCL).
* `injectInto(DiskImage*, TRDOSDirectoryEntry* placed = nullptr)`: adds the file to an existing TR-DOS image at
  the first free track/sector recorded in the volume sector (track 0 sector 9). The caller (emulator / UI) decides
  whether the disk in the drive is the target; the loader does not look at the drive.
* Shared step `LoaderHobeta::addFile(image, TRDOSDirectoryEntryBase, data, warnings, placed)` — the algorithm of
  `LoaderSCL::addFile`, with all validation done **before** any write:
  1. track 0 sectors 1..9 are 256-byte sectors with data fields and the volume sector carries the TR-DOS signature;
  2. `fileCount < 128`, `freeSectorCount ≥ sectors`;
  3. every sector of the chain `firstFreeTrack × 16 + firstFreeSector …` exists as a 256-byte sector inside the
     image (TR-DOS track `t` = `getTrack(t)`, sector `getSector(locator % 16)`).
  Then: 16-byte catalog entry into `getSector(entryIndex / 16)` at `(entryIndex % 16) × 16`, volume sector
  `fileCount++`, `freeSectorCount −= sectors`, first free locator advanced, body copied through the chain.
  Writes go through `Track::writeSectorData` (dirty flags + data CRC) followed by `recalculateDataCRC()` on
  every touched sector. A refused injection leaves the image byte-for-byte untouched with the dirty flag unchanged.

**Deviation from the draft:** the draft proposed moving `addFile` out of `LoaderSCL` into a shared `TRDOSCatalog`
helper. `loader_scl.*` was out of scope for editing, so the shared step lives as `LoaderHobeta::addFile` (static,
image-parametrised); `LoaderSCL::addFile` is unchanged. Folding SCL onto it is a follow-up.

## 3. Save (export)

`writeImage(path)` exports one catalog entry back to a `$`-file: header from the `TRDOSDirectoryEntry`, checksum
recomputed, data by walking the sector chain via `getSector(locator % 16)->data`. Selection:
`setExportEntry(index)` (0-based catalog slot, takes precedence), else `setExportName("name")` (space padded to
8), else the first non-deleted file. Byte 0x0D is written back verbatim when the exported file is the one this
loader instance read (same name and type), otherwise 0. `listFiles(DiskImage*)` returns the non-deleted catalog
entries together with their slot index. Exporting a file does not save the disk: no `markClean`, no file-path
update, no `NC_FDD_DISK_WRITTEN` (those belong to the disk writers).

## 4. Findings

* On a blank DS80 disk the file lands at TR-DOS track 1 sector 0 (cylinder 0, side 1, sector 1), the volume sector
  reads `fileCount = 1`, `freeSectorCount = 2544 − 3`, `firstFreeTrack = 1`, `firstFreeSector = 3`, and
  `LoaderTRD::validateTRDOSImage` accepts the result.
* On `insult.scl` (4 files, 731 sectors) the file is appended right after `boot` at locator `16 + 731`, exactly
  the volume sector's first free locator; existing entries are untouched, the image becomes dirty (track 0 and
  the file's track), and remains a valid TR-DOS disk.
* The WD1793 reads the injected sectors (256 bytes) on both a blank disk (cylinder 0 side 1) and the SCL disk
  (TR-DOS track `t` → cylinder `t / 2`, side `t % 2`) with `_beta128Register = BETA_CMD_RESET`.
* `Track::writeSectorData` only touches a sector when the content changes, which is what keeps the "image untouched
  on refusal" guarantee trivial: refusal paths never reach a write at all.

## 5. Fixtures

0x0D = 0, valid checksum — and `bad-checksum.$C` (same file, low checksum byte XOR 0x5A), both generated by
`core/tests/emulator/io/fdc/tools/mgt_hobeta_generator.py`. `insult.scl` (existing SCL fixture) is the
