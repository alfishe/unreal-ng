# Returning results

One folder per run: `results/<yyyymmdd>-<core version>-<board>/`, holding

- the photos (`h1timing.jpg`, `h2dma.jpg`, `h3sprites.jpg`, `h4z80n.jpg`);
- `notes.md` with: core version (boot screen), board issue (2 / 4 / 5 / KS2 / ...), RAM size, video mode (50 / 60 Hz,
  HDMI / VGA), anything unusual (an expansion bus device, a different CPU speed in the menu).

Transcribed numbers go into a table named like the tables in [../experiments.md](../experiments.md), so the comparison
with the prediction is mechanical.
