# MB-02 raw image (.mb2, .mbd)

## Overview

The 1024-byte sectors of an MB-02 (BS-DOS 199..308) floppy one after another in logical order, no header. `.mb2` is
Busy's form (the BS-DOS system disk `SYS308.MB2`), `.mbd` RealSpectrum's; both are the same bytes.

- **Extensions**: `.mb2`, `.mbd` (any extension works: the boot sector decides)
- **Sizes**: tracks x 2 x SPT x 1024: HD 80 / 82 x 2 x 11 (1 802 240 / 1 847 296 bytes), DD 80 x 2 x 5 (819 200 bytes,
  the size of an MGT image)
- **Loader / writer**: `core/src/3rdparty/unreal-disk/src/loaders/loader_mb02.cpp` (`LoaderMB02`)
- **Format id**: `mb02` (`FloppyFormats::Probe`, `Medium::Format`)
- **File system**: `mb02` volume, read and written ([disk file systems](../../emulator/design/disk-file-systems.md#mb-02-layout))

## Layout

Logical sector `LSN = 2 * SPT * track + SPT * side + (sector - 1)`: cylinder-major, side 0 then side 1, sector ids
1..SPT. The image holds LSN 0, 1, 2, ... in turn.

## Detection

By the boot sector (LSN 0), before the TR-DOS and MGT rules: `#18` at #00 (JR), `#02` at #03 (MB-02), 2 sides at
#08, 1 sector a cluster at #0A, `#00` at #20 and #25, and the tracks (#04, at most 86) x 2 x SPT (#06, at most 22) x
1024 equal to the file size. A DD MB-02 image therefore stays MB-02 although it has the MGT size; without the marks
the MGT rule takes it. Over the 107 585 files of the test data and the ZX collection only `SYS308.MB2` matches.

## Mapping to the model

Every track is an MFM track of SPT sectors of 1024 bytes (N = 3), ids 1..SPT, in the IBM layout with the widest gap 3
that fits (40 down to 8 in steps of 4: 24 on an 11-sector HD track). More than 5 sectors make an HD track of 12 500
bytes (500 kbit/s), else a DD track of 6 250 bytes.

## Saving

The sectors are written back in LSN order while the layout is regular: two sides, every track with the same SPT
sectors 1..SPT of 1024 bytes. Otherwise the save is refused with the reason (export as UDI to keep it). A loaded
image writes back byte for byte (`Mb02Fs.SystemDiskTreeAndBodiesMatchItsTapes`).
