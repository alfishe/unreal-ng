# Stream Deck glyphs

> Generated by `tools/icons/streamdeck_icons_doc.py` from `data/streamdeck/icons/glyphs.json`: do not edit by hand.

148 glyphs in 12 groups; 88 catalogue actions have a face, 7 are pruned (no key face). Every pack in `data/streamdeck/icons/packs/` draws all of them: `banner`, `duotone`, `glowicons`, `keycap`, `line`, `magicwb`, `newicons`, `os4`, `workbench13`. How the packs are made and changed: [README.md](README.md).

A glyph id ending in `.on` is the state variant of the glyph without it: the face while the action's readout is true. "Used by" lists the catalogue actions showing the glyph (`id` = its face, `id` on = its on face with the readout, `id` value = for that parameter value) and the menus / navigation keys.
