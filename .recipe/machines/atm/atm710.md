# Recipe: ATM Turbo 2+ v7.10 (`ATM710`)

Model `ATM710` (default 1024 KB; 128, 256, 512, 1024): ATM-Turbo 2+ v7.10, full `#xx77` control-port decode,
its own IDE (`Scheme=ATM`). Not a ZX-Evo and not a BaseConf board (that is `ATM3`:
[atm3-zxevo-baseconf.md](atm3-zxevo-baseconf.md)). Common material for all ATM models (creating, ports, video modes,
CP/M mode, pitfalls): [README.md](README.md).

## What software writes

- ATM 7.10 decodes `#FE` on **A2..A0 = 110** (since 2026-10-02; before, A0
  alone). `#FA` (010) and `#FB` (011) are the **INTERNAL I/O** port pair:
  `OUT (#FB)` latches an 8-bit bus address (the same latch feeds the printer
  and the Covox DAC), `IN` / `OUT (#FA)` reach the device that address
  selects - the ATM2IOESP Wi-Fi card ([network.md](../../peripherals/network.md)).
  With no device an `IN (#FA)` reads #FF; it never reaches the keyboard
  controller; an `IN (#FB)` reads the printer status (#FF without a printer),
  not the latch. At 7 MHz every RAM access waits 2-3 T (the contention report's
  `atm710_turbo_waits`) and every WD1793 access (#1F / #3F / #5F / #7F) 1 T.
- The keyboard controller (v7.xx board, `[ATM] Kbc=`, default V41) answers
  every `IN #FE` and holds the Z80 until it does. On v4.x **Ctrl+Alt+Ins**
  (keypad 0) blocks it - `IN #FE` then reads the plain matrix, no wait - and
  **Ctrl+Alt+Home** (keypad 7) unblocks it (the release notes have the keys the
  other way round; the firmware decides). A board reset restarts the 8031 too.
- `#FF77` — **ATM control register**: video mode select, CPU turbo,
  memory swap, INT gate. Decoder bits worth knowing: bit 8 `PEN` enables
  ATM paging, bit 9 selects TR-DOS vs **CP/M mode**, bit 14 (`pen2`)
  disables palette writes.
- `#FFF7` — **memory manager**: four window registers (window chosen by
  A15:A14), so ATM code can remap all four 16K windows, not just 0 and 1.
- `#EFF7` — extended control (3.5 MHz turbo request, ROCACHE).

## TR-DOS cold start and 128K programs

The DOS ROM's cold start (`#0000` -> `#3C50`, every ATM2 BIOS; also the BIOS menu's "TR-DOS 48" entry) probes RAM
page 31 for a resident and, when there is none, leaves window 3 of the `#7FFD.4 = 1` set over base 24: on 256 KB and
up a program's `#7FFD` page n is RAM 24 + n, while the picture stays in RAM 5 / 7 (1 / 3 for the ATM modes). That is
the ROM, emulated as it is. The **disk autostart** boots the 128K way instead ("SPECTRUM 128", then its menu's
TR-DOS): window 3 = `#7FFD` pages 0-7 in both sets. A 128K program booted by hand through "TR-DOS 48" still sees
pages 24-31. Investigation: [docs/inprogress/2026-10-11-atm-autostart-128k-paging](../../../docs/inprogress/2026-10-11-atm-autostart-128k-paging/README.md).

The disk autostart and SNA / Z80 snapshot loads keep the **CPU clock** the machine ran at (`#FF77` bit 3, 7 MHz; on
the ATM3 also `#EFF7` bit 4): their quick reset skips the BIOS that sets the clock after a real reset. A real reset
clears `#FF77`: 3.5 MHz until the BIOS or the program selects turbo.

## Hard disk

The ATM IDE board (`[HDD] Scheme=ATM`): units are the media slots `ide0.master` (alias `hd`) and `ide0.slave`.
Insert while paused. Verbs and formats: [use-media-slots.md](../../media/use-media-slots.md).

```text
media {"action":"insert","slot":"hd","path":"/home/me/zx/disk.img"}
inspect_state {"aspects":["ide"]}
```

What boots from it depends on the BIOS:

- The shipped BIOS 1.07.13 (`atm2.rom`): its CP/M has the HDD driver, and drive D: is the hard disk.
- iS-DOS / TASiS from the hard disk need xBIOS 1.35XT (`rom/xbios135.rom`, 128 KB), which no shipped config uses.
  Point the model at it with `ATM2=rom/xbios135.rom` and comment out `ROMSET` (it forces four pages). Then use
  Setup -> Boot -> "IDE hard drive master", which brings up the TASiS start menu. On ATM_HDD.HDD, TASiS 5.40 runs
  from C: and iS-DOS Chic 5.01 from D:.

## iS-DOS floppies

The disk autostart boots iS-DOS / TASiS floppies (`load_software` with `autostart`). By hand: the BIOS menu
"SPECTRUM 128", then TR-DOS from the 128 menu, then `RUN`. "TR-DOS 48" from the BIOS menu leaves the #7FFD pages
at RAM 24-31, and TASiS hangs there, as it does on the real machine. The keyboard goes through the KBC: TASiS needs a
key held for about 8 frames (`type_input` `tap` with `frames`).
