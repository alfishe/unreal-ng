# Recipe: ZX-Spectrum 48K + Beta 128 (TR-DOS)

A 48K with the Technology Research Beta 128 disk interface on its edge connector: the Leningrad-like target for
software written for a 48K with TR-DOS (no 128K paging, no AY). The plain `48K` model has no TR-DOS ROM, so a
TR-DOS disk does nothing there.

Ground truth: the variant in [machinevariants.cpp](../../core/src/emulator/machinevariants.cpp) (`48K-BETA128`),
the ROM load in [rom.cpp](../../core/src/emulator/memory/rom.cpp) (`[ROM] TRDOS=`), the paging in
[memory.cpp](../../core/src/emulator/memory/memory.cpp) (`Memory::IsDosAvailable`, `UpdateZ80Banks`), the port gate
in [portdecoder_spectrum48.cpp](../../core/src/emulator/ports/models/portdecoder_spectrum48.cpp), tests in
[beta128_test.cpp](../../core/tests/emulator/machines/spectrum48/beta128_test.cpp).

## Setup

- **The machine:** `48K-BETA128` (aliases `48K-TRDOS`, `48K-BETA`), a machine variant of `48K` (48 KB RAM).
  Every automation surface creates it by name and lists it with the models (`variant: true`, `base_model: "48K"`);
  an instance reports `variant: "48K-BETA128"`. unreal-qt: Machine menu -> **ZX-Spectrum 48k + Beta 128 (TR-DOS 5.03)**.
- **What it does** (the real interface: FUSE `beta.c`, MAME `bus/spectrum/beta128.cpp`):
  - the TR-DOS 5.03 ROM (`data/rom/trdos503.rom`, the version the 48K Beta 128 shipped with) is ROM page 1; it pages
    in on an M1 at `#3D00-#3DFF` and out on an M1 at `#4000` and above;
  - the WD1793 `#1F #3F #5F #7F` and the system register `#FF` decode the low byte only and answer only while the
    TR-DOS ROM is paged in: outside it a read is the floating bus and a write is dropped;
  - no `#7FFD`: a write there pages nothing;
  - drives `fdd.a`-`fdd.d` are the usual media slots.
- **The same board from an ini** (`configs/spectrum48/unreal.ini`): `[BETA128] Beta128=1` and
  `[ROM] TRDOS=rom\trdos504t.rom` (any 16 KB TR-DOS image).
- **Entering TR-DOS:** `RANDOMIZE USR 15616` (the `A>` prompt), or `RANDOMIZE USR 15619: REM : <command>` from BASIC
  (`CAT`, `RUN "boot"`, `LOAD "name"`). A reset does not boot the disk (the 48K ROM has no TR-DOS menu entry):
  type the command, or `RESET=DOS` in `[MISC]` to start in TR-DOS.

## MCP (preferred)

```text
emulator_manage {"action":"create","model":"48K-BETA128"}
media {"action":"insert","slot":"fdd.a","path":"/path/game.trd"}       # .scl / .trd
type_input {"action":"type","text":"RANDOMIZE USR 15619: REM : RUN \"boot\"\n"}
inspect_state {"aspects":["paging"]}                                      # ROM page 1 = TR-DOS v5.03 while in DOS
```

## WebAPI

```bash
curl -s -X POST "$BASE/emulator/start" -H 'Content-Type: application/json' -d '{"model":"48K-BETA128"}'
curl -s "$BASE/emulator/models" | jq '.models[] | select(.name=="48K-BETA128")'
```

CLI: `start 48K-BETA128`; `models` lists it under "Machine variants".

## Pitfalls

- **Software that probes `#7FFD`** (128K detection) sees a 48K: nothing pages.
- **A Kempston joystick on `#1F`** answers only outside TR-DOS, as behind a real Beta 128.
- **TR-DOS 5.03 is the 1986 ROM.** A program that needs 5.04T runs on the ini form above with `TRDOS=rom\trdos504t.rom`.
